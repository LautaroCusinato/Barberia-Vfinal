# Evidencia UI · Sprint 4

Capturas tomadas con Playwright contra el servidor Vite en modo demo, sin Supabase configurado y sin efectos externos. Convención: `after-{pantalla}-{viewport}-{tema}.png`.

- Viewports: desktop 1440×900, tablet 834×1112, mobile 390×844.
- Temas: light y dark.
- Pantallas: Clientes, Operación, Equipo y Configuración.
- Chequeos por captura: heading visible, ancho del documento y body sin overflow horizontal, sin errores de consola ni `pageerror`.

El baseline histórico se mantiene en [docs/UI-UX-AUDITORIA.md](../UI-UX-AUDITORIA.md) y en las carpetas de Sprint 2/3; estas imágenes son la evidencia posterior al Sprint 4.
